RBC Floorplan User Story

User story:
As an insurance product user,
I want to select and configure the RBC Floorplan option during policy setup,
so that the policy reflects the required floorplan coverage and can be processed correctly.

Acceptance Criteria:

1. The RBC Floorplan option is available when the applicable policy line is selected.
2. The user can select RBC Floorplan and provide all required information.
3. The system validates the selection before allowing the policy to proceed.
4. The selected RBC Floorplan details are saved and displayed in the policy summary.
